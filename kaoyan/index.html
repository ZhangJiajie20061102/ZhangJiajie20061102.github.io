2027 考研关键节点

标「预计」的是按往年规律推算，2027 年以研招网正式公告为准。

    现在这个阶段该干什么：报名已经关闭，网上确认在 11 月上旬完成，剩下的只有一件事—— 把每天的复习量固定下来，别再改计划。准考证考前 10 天左右开放下载，建议一次打印三份。

    国家线（进入复试的初试成绩基本要求）

    数据来自教育部公布的官方文件。国家线是门槛，不是录取线 —— 过线只代表有资格参加复试或被调剂。

    分数分布分析

    把某校某专业近年拟录取名单的初试总分粘进来（空格、逗号、换行都行）。 分数只存在你的浏览器里，不上传、不联网。

    目标池

    在「分数分布」里分析完一个目标，点「存为目标」就会出现在这里。按分位自动分成冲 / 稳 / 保。

    分档规则：以你的分数在样本里的 z 值为准。z ≥ 1.5 视为保底；0.8 ≤ z < 1.5 为稳妥； 0 ≤ z < 0.8 为擦线；z < 0 为冲刺或高风险。
    为什么要用分布而不是一条线：同一所学校的录取分每年浮动十几分是常态，用单条线判断会失真； 用分位判断，等于问「在这批人里我排第几」，这个结论跨年份更稳。
